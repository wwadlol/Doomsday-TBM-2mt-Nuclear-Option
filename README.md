# Doomsday-TBM-2mt-Nuclear-Option
Adds a new nuclear missile in the megaton range. This weapon is limited to only the Darkreach and Alkyon, priced at 250 dollarinoes each.
Made using NO-Blueprinter

Requirements:

BepinEx https://github.com/BepInEx/BepInEx/releases

Nikkorap's Blueprinter (goes into your BepinEx plugin folder) https://github.com/nikkorap/NOBlueprinter-Releases/releases/tag/2.0.1

You can also use NOMM to install BepinEx and Blueprinter more easily

Finally, place the .nopb file inside your BepinEx plugins folder and voila

!!!IMPORTANT!!! in Nuclear Option, AI pilots using the Darkreach and Alkyon can't really use modded weapons by default! They use something called standardized loadouts that the AI will pick from instead. (ever notice how they never use glide bombs?)

If you don't care about AI pilots not being able to use this nuke, then skip this step, otherwise get https://github.com/SonPamungkas/loadout-injector and follow the setup instructions.
Included in the "preset-loadout" folder, there are loadouts included for both aircraft. Just drop the Megaton.preset from and into the respective folders.
